# Generic Network Layer with Caching for SwiftUI

A modern, type-safe network layer built with Swift's native concurrency features, designed specifically for SwiftUI applications. This framework provides networking capabilities with built-in caching, comprehensive error handling, and full async/await support.

## Features

✅ **Full Concurrency Support** - Built with Swift's modern `async/await` and `actor` isolation  
✅ **Generic Request/Response** - Protocol-based design for any `Codable` type  
✅ **Flexible Caching** - Four cache policies for different use cases  
✅ **Type-Safe** - Leverages Swift's type system for compile-time safety  
✅ **Error Handling** - Comprehensive error types with detailed descriptions  
✅ **SwiftUI Optimized** - Designed for seamless integration with SwiftUI views  
✅ **Thread-Safe** - Actor-based isolation ensures thread safety  
✅ **Testable** - Fully unit tested with mock support


### Core Components

1. **NetworkRequest Protocol** - Defines the contract for network requests
2. **NetworkService** - Handles network operations and caching logic
3. **CacheManager** - Manages in-memory caching
4. **NetworkError** - Comprehensive error types
5. **CachePolicy** - Defines caching strategies
